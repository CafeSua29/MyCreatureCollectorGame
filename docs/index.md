# Mục lục chi tiết

> Một phần tài liệu project. Quy tắc chung: `CLAUDE.md` ở thư mục gốc.

Bảng chi tiết của mục lục (nội dung chính, tên mục, code liên quan của từng file). **"mục X" / "xem X" trong docs và comment code là tên mục trong bảng này.** `CLAUDE.md` chỉ giữ tên file theo nhóm. Tạo / tách file md thì thêm tên vào đúng nhóm ở `CLAUDE.md` và dòng chi tiết ở đây.
