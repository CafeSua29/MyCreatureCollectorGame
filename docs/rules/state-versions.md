# Lịch sử version save

> Một phần tài liệu project. Mục lục và quy tắc chung: `CLAUDE.md` ở thư mục gốc. Các tham chiếu "mục X" / "xem X" tra tên mục trong `docs/index.md` (mục lục chi tiết).

Mỗi lần đổi cấu trúc `GameState` / quái: tăng `SAVE_VERSION`, viết bước migrate (mục "Migrate" ở `state.md`) và thêm một dòng ở cuối danh sách này.
